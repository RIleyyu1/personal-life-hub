# 个人生活助手

为自己定制的健康生活网站：拍照记每一餐、记录训练、每天称重，自动算出每日消耗和营养目标，并随真实体重变化自我校准。

- **手机**：负责每天的记录（拍照记餐、训练、称重、设置）。
- **电脑**：只读的数据总览（趋势图、每日明细、个人纪录），不做记录。

设计文档见 [docs/DESIGN.md](docs/DESIGN.md)。

## 本地运行

需要 Node.js 22.13 或更高版本（用到内置的 SQLite）。

```bash
npm install            # 只装一个依赖：Claude SDK（用于拍照识别）
cp .env.example .env   # 填入 ANTHROPIC_API_KEY；不填也能跑，识别会用演示数据
npm start              # 或 npm run dev（改后端代码自动重启）
```

启动后终端会打印两个地址：

- 电脑（查看数据）：`http://localhost:3000`
- 手机（每日记录）：`http://<电脑局域网 IP>:3000`（手机和电脑连同一个 Wi-Fi）。在手机浏览器里选「添加到主屏幕」，用起来就像一个 App。

同一个地址会按设备自动分工：触屏设备进入记录界面，用鼠标的电脑进入数据总览。开发时想在电脑上调试手机界面，可以在地址后加 `?mode=phone`（或用浏览器开发者工具的手机模拟）；`?mode=desktop` 反过来。

数据（SQLite 数据库 + 照片）保存在 `data/`，已被 git 忽略，只在你自己的电脑上。

  index.js      HTTP 服务、路由、静态文件
  api.js        业务逻辑：档案、体重、餐、训练、仪表盘
  nutrition.js  BMR / TDEE / 营养目标 / 体重反推 TDEE（纯函数）

  exercises.js  动作库、常用调料种子数据

## 第一版包含

- **我的**：个人参数、四种目标（减脂 / 维持 / 增肌 / 重组）随时切换并保留历史、运动热量计入比例
- **记一餐**：拍照 → AI 识别出每样食物的重量和营养 → 可改名、改重量（营养素按比例联动）、整体份量缩放 → 点选调料补充隐形热量 → 保存
- **长期记忆**：改过的食物按每 100g 记下来，下次识别时作为参考；调料按使用次数排序
- **训练**：动作库（可自定义）、力量训练记组 × 次 × 重量、有氧记时长，按 MET 估算消耗；个人纪录（估算 1RM）
- **体重**：每日记录、7 天平均趋势线；kg / lb 一键切换（数据统一按 kg 保存，训练重量同样跟随）；新体重和最近平均差 5% 以上时会先确认，防止单位填反
- **今天**：热量环、三大营养素和纤维进度、饮食和训练列表、规则建议
- **自适应 TDEE**：积累 14 天以上体重和饮食记录后，用体重变化反推真实消耗，逐步取代公式估算值
- **电脑端总览**：近 7 / 30 / 90 天的平均摄入、热量和蛋白质达标天数、体重变化、训练次数；每日热量、体重、蛋白质、各部位训练组数四张图；可展开的每日明细（当天照片、食物、训练组）；档案、个人纪录、长期记忆。过去的日子按当时生效的目标计算
